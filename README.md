# Crash Catcher

Маленькая тулза для отладки игр на **Unity** и **Unreal Engine 5**. Она следит за логом (`Player.log` или `<Проект>.log`), ловит ошибки (в Unity — NRE, MRE, IOE и любые `*Exception`, в UE — краши, `check`, `ensure`, Accessed None, ошибки Blueprint) и краши движка и сразу просит NVIDIA App сохранить последние N минут записи экрана (Alt+F10). Ролик переименовывается по ошибке, рядом кладётся `.txt` со стеком.

Поверх игры висит небольшой виджет-консоль. Его можно закрепить (тогда клики проходят сквозь него в игру), а прозрачность фона меняется ползунком.

Нужна только Windows 10/11: .NET Framework 4.8 в ней уже есть. Устанавливать ничего не надо.

---

## Быстрый старт

1. **NVIDIA App**: включи «Мгновенный повтор» (Alt+Z → Запись → Мгновенный повтор) и выставь длительность, нужную вам. Клавиша сохранения по умолчанию Alt+F10.
2. Запусти `CrashCatcher.exe`. При первом запуске откроются настройки.
3. Вкладка **«Лог игры»**: выбери **движок** (Unity / Unreal Engine 5), нажми «Найти логи ▾» и выбери свою игру (или укажи путь вручную). Если выбрать лог другого движка, переключатель встанет сам.
   - Unity: билд пишет в `%USERPROFILE%\AppData\LocalLow\<Company>\<Product>\Player.log`.
   - UE5: редактор и PIE пишут в `<Проект>\Saved\Logs\<Проект>.log`, собранная игра — в `%LOCALAPPDATA%\<Игра>\Saved\Logs\`.
4. Вкладка **«Клипы»**: проверь папку, куда NVIDIA App сохраняет видео (NVIDIA App → Настройки → Запись → Расположение видео). По умолчанию стоит системная папка «Видео», подпапки просматриваются.
5. Вкладка **«Запись»** → **«Тест (через 3 с)»**. Переключись в игру. Через 3 секунды тулза нажмёт Alt+F10, дождётся ролика и напишет в виджете, что он сохранён. Если так и случилось, всё работает.

> Если игра запущена **от администратора**, запусти тулзу тоже от администратора. Иначе Windows не пропустит нажатие клавиш.

## Виджет

| Кнопка | Что делает |
|---|---|
| ● | Сохранить клип прямо сейчас |
| ‖ / ▶ | Пауза / продолжить слежение |
| 🗑 | Очистить консоль |
| 📌 | Закрепить: клики пойдут сквозь виджет в игру |
| ⚙ | Настройки |
| – | Скрыть виджет (останется значок в трее) |

- **Перетаскивание**: за заголовок или нижнюю полосу. **Размер**: уголок справа внизу.
- **Ползунок «Фон»** меняет прозрачность фона. Текст остаётся непрозрачным, у него есть тень для читаемости.
- **Клик по строке ошибки** раскрывает стек. Там есть кнопки «Копировать», «Открыть клип» и «Показать в папке».
- Одинаковые ошибки сворачиваются в одну строку со счётчиком (×120). В заголовке видны итоги по типам: `NRE 120 · MRE 1`.
- Значок справа от строки показывает состояние клипа: часы — ждёт сохранения, стрелки — NVIDIA пишет файл, видео — сохранён (кликни, чтобы открыть), треугольник — проблема.

**Горячие клавиши** (меняются в настройках):
- `Ctrl+Shift+F11` — показать / скрыть виджет;
- `Ctrl+Shift+F9` — очистить консоль;
- `Ctrl+Shift+F12` — закрепить / открепить. Закреплённый виджет мышь не ловит, поэтому открепить его можно только этим сочетанием или из меню значка в трее.

Виджет виден поверх игры в **оконном и безрамочном** режиме (в Unity это Fullscreen Window, режим по умолчанию). Эксклюзивный полноэкранный режим перекрывает любые окна.

## Когда сохраняется клип

- **Исключения** (`NullReferenceException`, `MissingReferenceException`, `InvalidOperationException`, любые `…Exception`): через 3 с после ошибки, чтобы в ролик попали последствия.
- **Нативный краш Unity** (`Crash!!!`): сразу.
- **Не чаще раза в 60 с.** Ошибки, случившиеся, пока клип ждёт своей очереди, попадают в тот же клип: буфер 5 минут их захватывает.
- **Спам одной ошибкой** (NRE каждый кадр) даёт один клип. Повторный клип по той же ошибке будет, только если она молчала 5 минут и появилась снова.
- `Debug.LogError` и Assert только показываются в консоли. В настройках («Правила») можно включить клип и для них.

Все числа настраиваются на вкладке «Запись».

### Unreal Engine 5

| Правило | Пример строки | Метка | Клип |
|---|---|---|---|
| Краш / Fatal | `=== Critical error: ===`, `appError called:`, `Unhandled Exception:` | CRASH | сразу |
| check() | `Assertion failed: …` | CHECK | да |
| ensure() | `Ensure condition failed: …` | ENSURE | да |
| Accessed None | `LogScript: Warning: Accessed None trying to read property …` | NONE | да |
| Blueprint Runtime Error | `Blueprint Runtime Error: "…"` | BP | да |
| Любой `Error:` | `LogTemp: Error: …` | ERR | нет, только консоль |
| Исключение (ignore) | ensure редактора при старте: `r.… is deprecated`, `AssetBaseClassLoaded` | — | отбрасывается |

- Префикс `[время][кадр]` в начале строк срезается, `[File:…] [Line: N]` сокращается до `Файл.cpp:N`.
- Колстек (`[Callstack] 0x…`, `Stack:`) и скрипт-стек Blueprint прикрепляются к ошибке и не считаются отдельными ошибками.
- Всё, что идёт сразу после краша (Assertion failed, колстек), склеивается в одну запись CRASH.
- При запуске UE переименовывает старый лог в `…-backup-….log` и начинает новый. Тулза это замечает и читает новый файл с начала.
- Ensure, которые сам редактор пишет при каждом запуске (устаревшие CVar `r.… is deprecated`, `AssetBaseClassLoaded`), отбрасываются правилом-исключением. Их не будет ни в консоли, ни в клипах.
- Свои исключения можно добавить на вкладке «Правила»: режим **ignore**. Если в тексте ошибки нашёлся шаблон, ошибка отбрасывается. Режим работает и для Unity.

У Unity и UE свои списки правил и свой путь к логу. Переключение движка ничего не стирает.

## Что получается на выходе

- Ролик в папке NVIDIA переименовывается так: `2026-10-15_23-40-12_NRE.mp4`. Время — момент первой ошибки, метка — её тип. `NRE+1` значит, что в клип попала ещё одна ошибка другого типа.
- Рядом лежит `.txt` с тем же именем. В нём ошибки, из-за которых сохранён клип, с полным стеком, и всё остальное, что было в логе за время буфера.
- `history\history_ГГГГ-ММ-ДД.log` рядом с программой — журнал всех ошибок и клипов за день.

## Правила (для продвинутых)

Вкладка «Правила» — это список регулярных выражений:
- режим **line**: строка сама является ошибкой. Группы `(?<type>…)` и `(?<msg>…)` необязательны: из `type` берётся метка (NullReferenceException → NRE);
- режим **marker**: строка стека, например `UnityEngine.Debug:LogError`. Текстом ошибки становится строка над ней;
- галочка **«Клип»** решает, сохранять ли видео по этому правилу.

Внизу вкладки есть поле «Проверить строку»: вставь строку из лога и увидишь, какое правило сработает.

## Если что-то не работает

- **«Новый ролик не появился за 60 с»**. Проверь три вещи: включён ли «Мгновенный повтор» в NVIDIA App, совпадает ли клавиша (Alt+F10) и правильная ли папка клипов. Если NVIDIA не реагирует на программное нажатие, попробуй в настройках «Способ нажатия → Виртуальные коды клавиш».
- **Клип не сохраняется после краша**: когда окно игры закрылось, NVIDIA может перестать писать. Включи в NVIDIA App запись рабочего стола (Настройки → Конфиденциальность → «Запись рабочего стола»).
- **Нажатие не доходит до игры или NVIDIA**: запусти тулзу от администратора.
- **Виджет не виден поверх игры**: переключи игру в оконный или безрамочный режим.
- **Горячая клавиша «занята»**: смени её на вкладке «Виджет».
- Если тулза упала, подробности будут в `CrashCatcher.error.log` рядом с программой.
